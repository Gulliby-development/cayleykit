# cayleykit

cayleykit is an offline command-line calculator for permutations and the groups they generate. It gives exact answers, including arbitrary-precision group orders, without a computer algebra system. It is for algebra students, puzzle and cube solvers, and anyone who needs exact answers about groups given by permutations.

[![CI](https://github.com/Gulliby-development/cayleykit/actions/workflows/ci.yml/badge.svg)](https://github.com/Gulliby-development/cayleykit/actions/workflows/ci.yml) [![License: MIT](https://img.shields.io/badge/license-MIT-blue.svg)](LICENSE)

## Install

Install the .NET 10 SDK, then build the Release version from the repository root:

```sh
dotnet build -c Release
```

The executable is `src/Cayleykit/bin/Release/net10.0/cayleykit` (with the platform's executable suffix, such as `.exe`, where applicable). You can also run it through the .NET host:

```sh
dotnet src/Cayleykit/bin/Release/net10.0/cayleykit.dll COMMAND
```

Replace `COMMAND` with one of the commands below and its arguments.

## Usage

Use `--help` by itself to print the command synopsis:

```text
usage: cayleykit show [--degree D] P
       cayleykit mul [--degree D] P Q...
       cayleykit pow [--degree D] P K
       cayleykit conj [--degree D] P Q
       cayleykit orbits [--degree D] G...
       cayleykit order [--degree D] G...
       cayleykit word [--degree D] P G...
       cayleykit elements [--degree D] G...
       cayleykit classes [--degree D] G...
       cayleykit centralizer [--degree D] P
```

Here `P` and `Q` are permutations, `K` is an integer exponent, and `G...` is a list of generators. Group commands accept one to eight generators. For those commands, a single `-` reads generator permutations from standard input, separated by whitespace.

For example, show the structure of a permutation:

```sh
cayleykit show "(1,2,3)(4,5)"
```

It prints:

```text
perm        (1,2,3)(4,5)
degree      5
image       2 3 1 5 4
order       6
sign        odd
type        3 2
inverse     (1,3,2)(4,5)
```

The pocket-cube example computes the exact order of the group generated by three quarter turns:

```sh
cayleykit order "(2,23,14,10)(4,21,16,12)(5,7,8,6)" "(1,3,4,2)(7,11,19,23)(8,12,20,24)" "(1,7,16,18)(2,5,15,20)(9,11,12,10)"
```

It prints:

```text
degree      24
gens        3
order       3674160
base        1 2 3 4 5 6
sizes       21 18 15 12 9 6
```

A word-search example finds a shortest expression for a target permutation:

```sh
cayleykit word "(1,3)" "(1,2)" "(2,3)"
```

It prints:

```text
order       6
length      3
word        g1 g2 g1
```

## Notation

A permutation is written in cycle notation. The identity is `()`; for example, `(1,2,3)(4,5)` describes two disjoint cycles. Quote permutation arguments in a shell so parentheses and commas are passed as one argument. Points are from 1 through 64, with no spaces, signs, leading zeroes, or repetitions in a permutation. Single-point cycles and malformed cycles are invalid. Points omitted from the notation are fixed.

Supply `--degree D` to choose a degree from 1 through 64. If it is omitted, the degree is inferred from the largest point mentioned, or is 1 when all permutations are identities. A product applies its permutations from left to right: `P Q` applies `P` first and then `Q`. Permutation and group orders are exact.

## Commands

`show [--degree D] P` displays the canonical permutation, its degree, one-line images, order, sign, cycle type, and inverse. A single `-` in place of `P` reads the permutation from standard input; a second permutation there is `too many arguments`.

`mul [--degree D] P Q...` multiplies two to eight permutations from left to right and reports the product, its degree, order, and sign.

`pow [--degree D] P K` reports the permutation's order, its power, and the exponent reduced modulo that order. The exponent is an integer from -1000000000000000000 through 1000000000000000000.

`conj [--degree D] P Q` reports `P`, the conjugating permutation `Q`, the conjugate, the commutator, and whether the two permutations commute.

`orbits [--degree D] G...` reports the generated group's exact order, its point orbits, each orbit's size and point stabilizer order, and whether the action is transitive.

`order [--degree D] G...` computes the generated group's exact order with a stabilizer chain and reports its base and orbit sizes.

`word [--degree D] P G...` finds a shortest word in the numbered generators for `P`, using generator-number order to break ties. The group may have at most 100000 elements; a permutation outside the group is reported with exit code 1.

`elements [--degree D] G...` lists all generated-group elements in ascending permutation order when the group has at most 500 elements.

`classes [--degree D] G...` lists the conjugacy classes, their sizes, representative orders and cycle types, and reports the center size and whether the group is abelian. The group may have at most 720 elements.

`centralizer [--degree D] P` reports the permutation's cycle type and, in the symmetric group of the chosen degree, the order of its centralizer (`commute`) and the size of its conjugacy class (`class`). Fixed points count as cycles of length 1. The centralizer order is the product, over the cycle lengths k, of k to the power m times m factorial, where m is the number of cycles of length k; the class size is the degree factorial divided by it.

```console
$ cayleykit centralizer --degree 7 "(1,2,3)(4,5)"
perm        (1,2,3)(4,5)
degree      7
type        3 2 1 1
commute     12
class       420
```

## Exit codes

Exit code 0 means the command succeeded. Exit code 1 is used only by `word` when the requested permutation is not in the generated group. Exit code 2 indicates a command-line or input error, including invalid notation or an operation that exceeds its documented size limit.

### Source

- `src/Cayleykit/Core/Text.cs` - Formats sanitized text, keyed output lines, and integer lists.
- `src/Cayleykit/Core/Ints.cs` - Parses bounded integers.
- `src/Cayleykit/Core/Options.cs` - Parses command options and positional arguments.
- `src/Cayleykit/Core/Io.cs` - Defines command I/O and reads generator words.
- `src/Cayleykit/Perms/Perm.cs` - Implements immutable permutations and their operations.
- `src/Cayleykit/Perms/Notation.cs` - Parses and formats cycle notation.
- `src/Cayleykit/Perms/Structure.cs` - Computes permutation structure and conjugation operations.
- `src/Cayleykit/Groups/Orbits.cs` - Computes the point orbits of a generated group.
- `src/Cayleykit/Groups/Chain.cs` - Builds stabilizer chains and computes exact group orders.
- `src/Cayleykit/Groups/Closure.cs` - Enumerates generated-group elements within a limit.
- `src/Cayleykit/Groups/WordSearch.cs` - Finds shortest generator words for group elements.
- `src/Cayleykit/Groups/Classes.cs` - Computes conjugacy classes.
- `src/Cayleykit/Commands/ShowCommand.cs` - Implements the permutation summary command.
- `src/Cayleykit/Commands/MulCommand.cs` - Implements permutation multiplication.
